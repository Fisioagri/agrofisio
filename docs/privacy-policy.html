Política de Privacidade

Nutrifisiologia Vegetal — Aplicativo Android

Última atualização: junho de 2026

1. Responsável pelo aplicativo

Nutrifisiologia Vegetal é desenvolvido e mantido por Rafael Schueroff de Meira.
Contato: fisioagri@gmail.com

2. Dados coletados

O aplicativo coleta apenas os dados estritamente necessários para o funcionamento dos serviços:

  • E-mail e senha — para criação de conta e autenticação.
  • Dados agronômicos — laudos, talhões, produtores e diagnoses inseridos pelo próprio usuário.
  • Imagens — fotografias de laudos de análise enviadas pelo usuário para leitura por OCR (processadas e descartadas, não armazenadas permanentemente).
  • Dados de uso — logs de acesso para fins de segurança e estabilidade do serviço.

3. Como os dados são usados

  • Autenticação e acesso à conta do usuário.
  • Armazenamento dos laudos e histórico do usuário.
  • Geração de diagnoses agronômicas por inteligência artificial.
  • Melhoria contínua do serviço.

Não utilizamos os dados para publicidade, nem os vendemos ou repassamos a terceiros.

4. Compartilhamento de dados

Os dados são processados pelos seguintes serviços de infraestrutura:

  • Supabase — banco de dados seguro hospedado na AWS (São Paulo, Brasil).
  • Cloudflare Workers AI — processamento de inteligência artificial (modelos rodando na borda, sem retenção de dados).
  • Anthropic Claude API — geração dos diagnoses agronômicos. Os dados enviados não são usados para treinamento de modelos (conforme contrato de API da Anthropic).

Nenhum dado é compartilhado com outras empresas, anunciantes ou parceiros comerciais.

5. Armazenamento e segurança

  • Todos os dados são criptografados em trânsito (HTTPS/TLS 1.3).
  • O banco de dados utiliza Row Level Security (RLS) — cada usuário acessa apenas seus próprios dados.
  • Senhas não são armazenadas em texto puro — utilizamos autenticação gerenciada pelo Supabase Auth.

6. Direitos do usuário

O usuário tem direito a:

  • Acessar todos os dados associados à sua conta.
  • Corrigir dados incorretos.
  • Solicitar a exclusão completa da conta e de todos os dados associados.
  • Exportar seus laudos em PDF a qualquer momento pelo próprio aplicativo.

Para exercer esses direitos, entre em contato: fisioagri@gmail.com

7. Menores de idade

Este aplicativo é destinado a profissionais agrônomos e técnicos agrícolas. Não coletamos intencionalmente dados de menores de 13 anos.

8. Atualizações desta política

Esta política pode ser atualizada ocasionalmente. Notificaremos usuários ativos sobre mudanças relevantes via e-mail ou notificação no aplicativo. A data da última atualização é indicada no cabeçalho desta página.
